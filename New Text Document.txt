────────────────────────────────────────
0. WHAT YOU ARE BUILDING (plain language)
────────────────────────────────────────
PARALLAX is a one-page immersive trading surface for TOKENIZED US STOCKS on BNB Chain.

A normal stock market closes \~16:00 New York time. Tokenized versions of the same names keep trading on-chain as BEP-20 tokens from three different issuers:

  • bStocks   suffix B     e.g. NVDAB    type=3   mixed SWAP (LiquidMesh) + RFQ (PcsXRfq)
  • Ondo      suffix on    e.g. NVDAon   type=1   RFQ only (InchFusion + CowSwap + PcsXRfq)
  • xStocks   suffix x     e.g. NVDAx    type=2   AMM SWAP like a normal token

These three tokens are NOT fungible. Same company, three contracts, three prices, three hour-rules.
Binance Web3 Trading API is the single aggregation layer. Quotes die in 30 seconds.
Ondo off US hours often returns error 40367. bStock off hours often returns 40369. xStocks pools may stay live.

PARALLAX:
  1. Maps “NVIDIA” / “NVDA” to every wrapper that exists on BSC.
  2. Quotes all of them live.
  3. Shows the PARALLAX: onchain price minus Friday 16:00 ET cash close (and vs the other wrappers).
  4. Routes a real spot buy/sell on the best OPEN rail (or the rail the user locked).
  5. Preflights SWAP txs with the Transaction Simulate API, then the user signs in Binance Web3 Wallet.
  6. Runs RFQ when the quote says executionMode=RFQ (EIP-712 → /order/submit → poll).
  7. Keeps an always-on agent (BNB Agent Studio + x402) for DCA / earnings flatten / weekend cap.
  8. Exposes the same router as MCP tools so Agent Studio / Claude / other agents can call it.

Judges open the deployed URL, connect a wallet, buy about $10 of a live name, see a BscScan hash.
Spot only. No perps. No new token. Fills land in the user’s wallet.

Tagline: Cash freezes. BNB doesn’t. Trade the gap.

3. DOMAIN MODEL (packages/core)
────────────────────────────────────────
type Rail = "bStock" | "ondo" | "xStock"
type ExecMode = "SWAP" | "RFQ"
type Session = "pre" | "regular" | "post" | "overnight" | "weekend" | "holiday"

interface Wrapper {
  rail: Rail
  type: 1 | 2 | 3          // ondo=1 xStock=2 bStock=3
  symbol: string           // NVDAB
  address: `0x${string}`   // BSC
  decimals: number
}

interface Underlying {
  ticker: string           // NVDA
  name: string
  wrappers: Partial<Record<Rail, Wrapper>>
}

interface VenueQuote {
  wrapper: Wrapper
  ok: boolean
  errorCode?: number       // 40367 40369 40401 QUOTE_EXPIRED etc
  errorText?: string
  executionMode?: ExecMode
  vendorName?: string
  quoteId?: string
  quoteExpiresAt: number   // Date.now()+30000 from receipt
  inAmount: string
  outAmount: string
  mid: number
  slipBps50: number
  slipBps500: number
  raw: unknown             // keep raw API body for DEVEX
}

interface Intent {
  ticker: string
  side: "buy" | "sell"
  usdt: string
  railLock?: Rail          // if set, no hop after confirm
  wallet: `0x${string}`
}

Router states (explicit enum, one store):
  idle resolving quoting selecting building simulating
  awaiting_signature submitting polling
  filled failed expired rail_closed

6. BINANCE WEB3 API (packages/web3)
────────────────────────────────────────
Docs to follow exactly:
  https://web3.binance.com/en/dev-docs/products/trading-api/introduction
  https://web3.binance.com/en/dev-docs/products/trading-api/integration-flow
  https://web3.binance.com/en/dev-docs/products/transaction-api/introduction

Trading (binanceChainId="56"):
  GET  /api/v1/dex/aggregator/quote
  GET  /api/v1/dex/aggregator/swap
  GET  /api/v1/dex/aggregator/quote-and-swap
  GET  /api/v1/dex/aggregator/approve-transaction
  GET  /api/v1/dex/aggregator/history
  POST /api/v1/dex/aggregator/order/submit
  GET  /api/v1/dex/aggregator/order/{orderId}

Transaction:
  GET  /api/v1/dex/pre-transaction/gas-price
  GET  /api/v1/dex/pre-transaction/block-height
  POST /api/v1/dex/pre-transaction/gas-limit
  POST /api/v1/dex/pre-transaction/simulate
  POST /api/v1/dex/pre-transaction/broadcast-transaction
  GET  /api/v1/dex/post-transaction/orders

Rules from docs you MUST implement:
  • userWalletAddress required on /quote for RFQ routes (Ondo always; bStock RFQ).
  • quoteId \~30s. After that 40401 QUOTE_EXPIRED. New quote, never reuse.
  • /swap params must match the cached quote.
  • slippagePercent OR autoSlippage=true required on /swap.
  • SWAP: sign data.tx, simulate evmTx, broadcast signed tx.
  • RFQ: sign rfq.typedDataToSign EIP-712, POST /order/submit { order, requestId }, poll until FILLED|FAILED.
  • requestId UUID. Retry = SAME uuid. New uuid = new order.
  • Signer address MUST equal userWalletAddress.
  • approve-transaction for equity needs vendor = vendorName from quote.
  • Trading + Transaction APIs never hold the key. You only relay signed payloads.

Auth: implement whatever the current Web3 API intro requires (API key headers). Env WEB3_API_KEY, WEB3_API_BASE.

7. EXECUTION PATH (only path)
────────────────────────────────────────
intent
 → resolve Underlying
 → in parallel quote every wrapper that exists (and USDT or chosen stable)
 → drop failed rails into the row as CLOSED/error
 → score OPEN rails by expectedOut after gas, minus slip penalty
 → BEST EXECUTABLE label
 → user hits BUY
 → lock rail + quoteId
 → if allowance low: build approve tx → user signs → broadcast → wait
 → GET /swap (if quote still young) else requote same rail
 → SWAP:
      POST simulate with the unsigned evmTx
      if SUCCESS show balanceChanges
      user signs
      POST broadcast-transaction
      poll history + post-transaction/orders
 → RFQ:
      user signs typed data
      POST order/submit
      poll /order/{id}
 → persist Tape row from CHAIN / order status, not from the quote
 → if user confirmed NVDAB, do not silently fill NVDAx

Caps: reject build if usdt > order cap or daily cap. Kill switch rejects build.
